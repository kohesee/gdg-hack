### Gemini CLI - Access AI Anywhere

A simple, lightweight CLI tool to access Google's Gemini AI from anywhere. Perfect for developers who want to integrate AI capabilities without complexity.

**Quick Start:**
```bash
npm install
export GEMINI_API_KEY=your_key
npm run cli
```

For detailed information, see [CLI_README.md](./CLI_README.md) and [DEPLOYMENT.md](./DEPLOYMENT.md).
